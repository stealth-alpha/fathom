How it works

Three steps from a repo to a shippable release artifact.

fathom init

Configure

Creates a documented fathom.config.json with sensible defaults — name, theme, policy, output.

fathom build

Generate

Reads your git history, source files and manifests to produce a changelog, SBOM and docs site.

fathom serve

Ship

Preview locally or drop fathom-dist/ on your CDN, Pages, Vercel or S3.

FAQ

Do I need to change my commit style?

No. Fathom understands conventional commits, but every other commit is grouped sensibly under Miscellaneous. Adopt conventional commits to get the best grouped changelog.

Is my code uploaded anywhere?

Not by the CLI. By default Fathom runs fully offline and reads your local repo. Hosted Pro features are opt-in.

How accurate is the SBOM?

It's generated from your manifests and local node_modules where available. It's best-effort and intended as a strong starting point for audit and compliance conversations.

What's the license?

The core CLI is MIT. Fathom Pro is a separate hosted product.
